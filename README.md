# Instagram AI Agent 🤖

Автоматический агент для Instagram: реагирует на ключевые слова в комментариях, отправляет DM, проверяет подписку и отправляет ссылку.

## Что делает агент

1. **Следит за комментариями** — ищет ключевые слова: "ремонт", "цена", "прайс", "info" и др.
2. **Отвечает на комментарий** — случайный вариант из 5 шаблонов
3. **Отправляет DM** — персонализированное сообщение с предложением
4. **Проверяет подписку** — через webhook-события Instagram
5. **Отправляет ссылку** — если подписан, сразу; если нет — после подписки или через follow-up

---

## Требования

- Node.js 18+
- **Бизнес-аккаунт Instagram** (подключённый к Facebook-странице)
- **Meta App** с доступом к Instagram Graph API
- HTTPS-сервер (для webhook) — можно использовать Railway, Render, или ngrok для теста

## Настройка Meta App (пошагово)

### 1. Создать приложение Meta
- Перейти на https://developers.facebook.com
- Создать приложение → тип "Business"
- Добавить продукт "Instagram Graph API" и "Messenger"

### 2. Получить токены
- Подключить Facebook-страницу к приложению
- Сгенерировать **Page Access Token** (долгосрочный, на 60 дней или постоянный)
- Скопировать **App Secret** из настроек приложения
- Скопировать **Page ID** вашей Facebook-страницы

### 3. Настроить webhook
В Meta App Dashboard → Webhooks:
- URL: `https://your-domain.com/webhook`
- Verify Token: то же, что в `.env` файле `WEBHOOK_VERIFY_TOKEN`
- Подписаться на события:
  - `comments` — комментарии к постам
  - `messages` — входящие DM
  - `follows` — новые подписчики

### 4. Разрешения (Permissions)
Запросить у Meta:
- `instagram_manage_comments` — для ответов на комментарии
- `instagram_manage_messages` — для DM
- `pages_messaging` — для Messenger API
- `instagram_basic` — базовый доступ

## Кастомизация

### Добавить ключевые слова
```js
// server.js, строка ~15
const KEYWORDS = ["ремонт", "цена", "прайс", "info", "ваше_слово"];
```

### Изменить шаблоны ответов
```js
// Ответы на комментарий
const COMMENT_REPLIES = [
  "Ваш текст ответа 1",
  "Ваш текст ответа 2",
  // ...
];
```

### Изменить ссылку
```env
TARGET_LINK=https://your-link.com
```

## Для продакшна

- Заменить `userState` (Map) на **Redis** или **PostgreSQL**

- Деплой на **Railway** / **Render** / **VPS**
