# Instagram AI Agent — Пошаговая инструкция

---

## Файлы проекта

```
instagram-agent/
├── server.js          ← основной агент
├── oauth.js           ← OAuth подключение через Meta
├── config.json        ← настройки (заполнить на шаге 3)
├── package.json       ← зависимости Node.js
└── public/
    └── index.html     ← дашборд управления
```

---

## ШАГ 1 — Получить данные из Meta for Developers

Открой: https://developers.facebook.com → твоё приложение

### Где найти ID приложения и секрет:
**Левое меню → Настройки → Основные**

На этой странице:
- **«Идентификатор приложения»** → скопируй, это `appId` в config.json
- **«Секрет приложения»** → нажми «Показать» → скопируй, это `appSecret` в config.json

---

## ШАГ 2 — Настроить Redirect URI для OAuth

**Левое меню → Варианты использования → Authenticate and request data from Instagram users**
→ нажми **«Настройка»** рядом с этим вариантом

Или: **Левое меню → Продукты → Instagram → Настройки API**

Найди поле **«URI перенаправления OAuth»** (или «Valid OAuth Redirect URIs»):
- Добавь: `https://ВАШ-ДОМЕН.com/auth/callback`
- Для теста с ngrok: `https://xxxx.ngrok.io/auth/callback`
- Нажми **«Сохранить изменения»**

---

## ШАГ 3 — Настроить Webhook

**Левое меню → Webhooks**

Нажми **«Подписаться на это объектное поле»** для объекта **Page** (Страница):

Заполни:
- **URL обратного вызова**: `https://ВАШ-ДОМЕН.com/webhook`
- **Токен подтверждения**: придумай любую строку, например `igagent_secret_2024`

Нажми **«Подтвердить и сохранить»**

После сохранения подпишись на поля:
- `comments`
- `messages`
- `follows`

---

## ШАГ 4 — Заполнить config.json

Открой файл `config.json` в любом текстовом редакторе (Блокнот, VS Code):

```json
{
  "appId": "ВСТАВЬ_ИДЕНТИФИКАТОР_ПРИЛОЖЕНИЯ",
  "appSecret": "ВСТАВЬ_СЕКРЕТ_ПРИЛОЖЕНИЯ",
  "redirectUri": "https://ВАШ-ДОМЕН.com/auth/callback",
  "verifyToken": "igagent_secret_2024",
  "accounts": [],
  "scenarios": [],
  "commentReplies": []
}
```

**Важно:**
- `appId` — «Идентификатор приложения» из Настройки → Основные
- `appSecret` — «Секрет приложения» из Настройки → Основные
- `redirectUri` — тот же адрес, что прописал в шаге 2
- `verifyToken` — та же строка, что прописал в шаге 3

## ШАГ 5 — Установить Node.js и запустить

Скачать Node.js: https://nodejs.org (версия 18 или выше)

Проверить установку: открой Терминал (Mac/Linux) или Командную строку (Windows):
```
node --version
```
Должно показать v18.x.x или выше.

Запустить агента:
```bash
cd instagram-agent
npm install
npm start
```

Открой в браузере: **http://localhost:3000**

---

## ШАГ 6 — Пробросить локальный сервер (для теста без домена)

Meta требует публичный HTTPS-адрес. Используй ngrok:

1. Скачать: https://ngrok.com/download
2. Запустить в отдельном окне терминала:
```bash
ngrok http 3000
```
3. Скопируй адрес вида `https://abc123.ngrok.io`
4. Замени `https://ВАШ-ДОМЕН.com` на этот адрес в:
   - `config.json` → поле `redirectUri`
   - Настройки Meta → поле «URI перенаправления OAuth»
   - Настройки Webhook → поле «URL обратного вызова»
5. Перезапусти сервер: `npm start`

## ШАГ 7 — Подключить Instagram-аккаунт через дашборд

1. Открой http://localhost:3000
2. Перейди в раздел **«Аккаунты»**
3. Нажми **«Подключить через Meta»**
4. Откроется окно Facebook — войди и выдай разрешения
5. Выбери Facebook-страницу, к которой привязан Instagram
6. Аккаунт появится в списке автоматически

**Требование к аккаунту:**
Instagram должен быть **«Бизнес»** или **«Автор»** и привязан к Facebook-странице.

Как привязать если ещё не привязан:
- Instagram → **Настройки** → **Аккаунт** → **Переключиться на профессиональный аккаунт**
- Затем → **Центр аккаунтов** → связать с Facebook-страницей

---

## ШАГ 8 — Настроить сценарии в дашборде

Раздел **«Сценарии»** → **«Новый сценарий»**:

- **Название** — например: «Запрос на ремонт»
- **Ключевые слова** — ремонт, цена, прайс, стоимость (каждое слово добавляй отдельно)
- **Текст DM** — первое сообщение которое уйдёт в директ
- **Аккаунты** — выбери к каким аккаунтам применять
- **Follow-up** — включи, если хочешь напоминание через 1 час

Нажми **«Сохранить»**

---

## ШАГ 9 — Добавить варианты ответов на комментарии

Раздел **«Ответы»** — добавь 5–8 вариантов фраз.

Примеры хороших ответов (не похожих на бота):
```
Написал(а) вам в директ, там всё подробно
Отправил(а) информацию в личные сообщения
В директе уже всё есть — загляните
Ответил(а) в личку
Написали вам — проверьте входящие
```

Советы: разная длина фраз, без восклицательных знаков в конце каждой, разные начала.

## ШАГ 10 — Деплой для постоянной работы

Для работы 24/7 нужен хостинг. Самый простой вариант — **Railway**:

1. Зарегистрироваться: https://railway.app
2. Создать новый проект → **«Deploy from GitHub»**
3. Загрузи файлы на GitHub (или используй Railway CLI)
4. Railway даст постоянный HTTPS-домен
5. Замени все адреса в Meta и config.json на этот домен

Альтернативы: Render.com, VPS с PM2.

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| Webhook не подтверждается | `verifyToken` в config.json должен совпадать с «Токеном подтверждения» в Meta |
| DM не отправляются | В Meta → Варианты использования → проверь что есть `instagram_manage_messages` и `pages_messaging` |
| Аккаунт не найден при OAuth | Instagram должен быть Бизнес/Автор и привязан к Facebook-странице |
| Ошибка «redirect_uri mismatch» | `redirectUri` в config.json должен точно совпадать с тем, что в Meta (включая https/http) |
| `Cannot find module` | Запусти `npm install` ещё раз |
| Токен истёк | Дашборд → Аккаунты → кнопка «Обновить токен» |
