Инструкция по настройке Meta

Шаг 1. Перейти на developers.facebook.com → Мои приложения → ваше приложение

Шаг 2. Настройки → Основные → скопировать ID приложения и Секрет приложения

Шаг 3. Facebook Login for Business → Настройки → Допустимые URI перенаправления OAuth → добавить URL из поля выше

Шаг 4. Webhooks → Подписаться на поля страницы → вставить URL webhook и токен подтверждения → подписаться на: comments, messages, follows

Шаг 5. Перейти в Аккаунты → нажать Подключить через Meta
