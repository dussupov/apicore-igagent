Инструкция Meta (шаги)

1. developers.facebook.com → ваше приложение → Настройки → Основные → скопировать ID и Секрет

2. Варианты использования → Access the Instagram Graph API → Настройка → добавить разрешения:
instagram_basic, instagram_manage_comments, instagram_manage_messages, pages_show_list, pages_read_engagement, business_management

3. Webhooks → Подписаться на поля страницы → вставить Webhook URL и Verify Token → подписаться на: comments, messages

4. Сохранить настройки ниже → перейти в Аккаунты → нажать «Войти через Facebook»
