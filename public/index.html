Инструкция по настройке Meta

Шаг 1. developers.facebook.com → ваше приложение → Настройки → Основные → скопировать ID и Секрет

Шаг 2. Facebook Login for Business → Настройки → Допустимые URI перенаправления OAuth → добавить Redirect URI

Шаг 3. Webhooks → Подписаться на поля страницы → вставить URL Webhook и Verify Token → подписаться на: comments, messages, follows
