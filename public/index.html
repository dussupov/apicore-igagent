Render
  1. Лучший вариант: Render → New → Blueprint → выбрать репозиторий с render.yaml. Он сам создаст PostgreSQL и Web Service.
  2. Если создаёшь вручную: сначала создай PostgreSQL, потом Web Service.
  3. Build: npm install
  4. Start: npm start
  5. В Environment добавь DATABASE_URL = Internal Database URL из Render PostgreSQL.
